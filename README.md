# ☕ The Coffee Economy

An interactive, browser-based economics game with seven rounds:

1. The Value of Time
2. Central Bank Monetary Policy
3. Commercial Banking
4. Banking Panic
5. Investment Portfolio
6. International Trade
7. Purchasing Power Parity

## Play

Open `index.html` in a browser. No installation or backend is needed. Progress saves locally in your browser.

## Publish on GitHub Pages

In your repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.

Once deployed, your game should be available at:

https://utopiafintech.github.io/coffee-economy/

All simulations are fictional educational examples, not financial advice.
